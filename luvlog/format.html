러브로그 · 글쓰기

본문 서식

툴바 버튼을 누르거나, 아래 문법으로 직접 감싸도 됩니다. 글은 열 때마다 원문으로 다시 그려지므로 서식 기능이 좋아지면 예전 글에도 바로 적용됩니다.

기본 서식

  • 글자를 드래그로 고르고 B · I · U · S · H, 또는 **굵게** *기울임* __밑줄__ ~~취소선~~ ==형광펜==
  • 문단 정렬(☰▾ — 가운데·오른쪽·양쪽·들여쓰기), 구분선(―▾ — 가는 선·굵은 선·점선·빗금·◆ 장식), 목록(1.≡ / •≡)
  • 글자 크기 {{18:글}}(8~72px), 글자색 {{#f00:글}} — 여러 문단에 걸쳐 열고 닫아도 문단마다 적용됩니다. 이 둘은 HTML 블록·HTML 모드 안에서도 씁니다.

접은 글 · 인용 · 링크

  • ▸ 접은 글 — 툴바 ▸ 또는 [접기:제목] … [/접기]. 읽는 사람이 눌러서 펼치는 상자. 접은 내용은 목록 미리보기(발췌)에 안 나옵니다.
  • ❝ 인용 상자 — 각 줄 앞에 >. 모양(세로선/따옴표/편지지)은 테마·레이아웃에서.
  • 🔗 글자 링크 — [보일 글자](https://주소)

사진과 영상

  • 사진을 첨부하고 본문에 [사진1] [사진2]를 쓰면 그 자리에 들어갑니다. 붙여넣기(Ctrl+V)나 끌어다 놓기로도 첨부됩니다.
  • 「⌘ MD 복사」 — 툴바 끝 버튼을 누르면 지금 쓰는 글이 마크다운으로 클립보드에 복사됩니다(접기→details, 사이드노트→각주, 사진은 주소). 글을 읽을 때도 주인에게 ⌘ MD 버튼이 보입니다. 노션·옵시디언·다른 블로그에 그대로 붙일 때.
  • 본문 장식 — 문단 앞 @d 로 드롭캡(첫 글자 크게), 글 안에 [주:내용] 으로 사이드노트(넓은 화면에선 오른쪽 여백에, 좁으면 본문 아래 작은 글씨), 사진 아래 ~ 로 시작하는 줄은 캡션, >" 는 큰 따옴표 인용, >~ 는 편지지 인용. 툴바의 정렬 메뉴와 ✦ 메뉴에서 넣을 수 있습니다.
  • 첨부 썸네일의 ☆를 누르면 대표 사진 — 글 목록·매거진 표지에 걸립니다(안 고르면 본문 첫 사진). 본문에 사진이 없어도 「🖼 썸네일 직접 올리기」로 따로 올릴 수 있으며, 대표 사진이 정해지면 확대·가로·세로 슬라이더로 목록(정사각)과 매거진(가로)에서 보일 부분을 조정할 수 있습니다. 「목록 썸네일」 셀렉트로 이 글만 목록에서 썸네일을 보이거나 숨길 수 있으며, 홈 전체 설정보다 우선합니다.
  • 유튜브 주소를 한 줄에 붙여넣으면 카드로 박힙니다.

💬 대화(말풍선) 서식

[톡:이름1/이름2] 줄과 [/톡] 줄 사이에 「이름: 대사」를 줄줄이 쓰면 말풍선 대화가 됩니다. 첫 인물이 왼쪽, 둘째가 오른쪽, 이름 없는 줄은 가운데 지문. 이름 뒤에 =#색상을 붙이면 그 사람 풍선에 색이 입혀집니다.

툴바 💬 팝업에서 모양(기본 / 메신저 흰 박스 / 무전 로그)·창 너비·풍선색·인물별 이름·색·프로필 사진까지 정하고, 〈프리셋 저장〉하면 다음 글에서 [톡@프리셋이름] 한 줄로 재사용됩니다. 페어가 여럿이면 프리셋을 여러 개 만들어 두세요.

🧩 HTML 블록 / HTML 모드

  • 본문 일부만 HTML로 넣으려면 [html] 줄과 [/html] 줄 사이에 코드를 씁니다. 바깥은 평소 서식, 안은 코드 그대로.
  • 글 전체가 HTML이면 「HTML 모드」 체크. 📄 HTML 파일을 그대로 올려도 되고, 코드 위·아래 일반 텍스트는 줄바꿈까지 그대로 보입니다.
  • 화면을 붙잡는 형태의 로그는 홈이 밀리지 않게 자동으로 액자에 격리되고, 일반 HTML 글엔 홈 커스텀 CSS가 그대로 적용됩니다.
📑 목차 — 큰 글자(18 이상)로만 쓴 짧은 줄이 2개 이상이면 글 상단에 목차가 자동으로 생깁니다.
