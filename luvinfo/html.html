HTML 페이지와 블록

직접 만든 HTML을 페이지 통째로, 또는 보통 페이지 안의 블록으로 넣을 수 있습니다. 스크립트도 실행돼요.

넣는 법

  • HTML 페이지를 만들고 코드를 붙여넣거나 📄 HTML 파일을 불러옵니다. 15만 자를 넘는 큰 HTML은 자동으로 따로 보관돼요.
  • HTML 페이지는 머리글이 자동으로 숨겨지고, 체크로 다시 켤 수 있습니다.
  • 보통 페이지에는 ＋HTML 블록으로 조각만. 페이지와 같은 대우(스크립트 실행·CSS 격리)예요.

알아둘 것

  • document에 이벤트를 다는 스크립트는 홈 전체에 걸리니, 페이지 안 요소에 다세요.
  • CSS는 그 페이지 안에서만 먹도록 격리됩니다. body·:root에 쓴 스타일은 페이지 영역으로 치환돼요.
  • position:fixed와 큰 z-index는 홈 화면을 덮지 않게 순화됩니다. 화면에 고정되는 요소는 만들 수 없어요.
  • 클래스 이름은 홈 자체 스타일과 부딪힐 수 있으니 고유한 접두어를 붙이세요.
  • @keyframes는 격리 과정에서 깨질 수 있습니다. 움직임은 transition·SVG·JS로.
  • iframe 높이는 height 속성이 그대로 존중됩니다.
HTML 때문에 편집 화면까지 깨졌다면 주소 뒤에 ?safe=1(HTML 페이지를 그리지 않음) 또는 ?nocss=1(직접 CSS 끄기)을 붙여 여세요.
