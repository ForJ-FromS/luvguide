백업과 복원

  • 꾸미기 → 기본 정보(관리)의 백업 — 꾸미기와 글·갤러리를 골라 원본 JSON(비밀글 암호화 원문까지)으로, 읽기용 HTML로도 저장.
  • 복원 — 그 파일로 되돌리기. 복원 직전 현재 상태가 자동 백업되고, 글 복원은 되살리기만(지금 글을 지우지 않음).
  • 다른 홈의 백업을 복원하면 사진(사진첩 포함)까지 이 홈으로 복사돼 새 주소로 이사됩니다(방명록·발도장은 이전되지 않습니다). 확인창에 누구 것인지·글 몇 편·백업 날짜가 보입니다.
  • 「홈 전체 내려받기 (zip)」 — 사진 파일까지 전부 담은 zip 하나입니다. 압축을 풀고 index.html을 열면 러브로그 없이도 홈이 그대로 보이고(글마다 페이지·갤러리·방명록), md/ 폴더에는 글마다 마크다운 파일(접기·사진·각주까지 변환)이, backup.json은 복원용 원본이 들어 있습니다. 그 폴더를 GitHub Pages 같은 곳에 올리면 개인 홈으로 쓸 수 있습니다. 사진이 많으면 1~2분 걸립니다.
  • JSON·HTML 백업은 사진을 링크로만 담으니, 진짜 보관은 zip으로 가끔 한 번씩.

⏪ 되돌리기(자동 백업)

꾸미기 저장·초기화·복원·듀얼 담기 직전 상태가 기기에 자동 저장됩니다(최근 12개). 관리에서 시각을 골라 되돌리면 글·사진은 그대로 두고 꾸미기만 돌아갑니다.

🔑 비밀글 복구 비밀번호

관리에서 하나 만들어 두면 글마다 다른 비밀번호를 써도 이 하나로 열고 새로 정할 수 있습니다. 앞으로의 비밀글엔 자동 적용, 예전 비밀글은 한 번 정상적으로 열어 두면 함께 적용. 운영자는 여전히 내용을 볼 수 없고, 복구 비밀번호까지 잊으면 방법이 없으니 꼭 적어 두세요.

🏠 홈 주소 변경

관리에서 @주소를 바꿀 수 있습니다. 옛 주소는 7일간 「이사했어요」 안내판으로 남아 링크가 자동으로 넘어가고, 그 뒤엔 풀려 다른 분이 쓸 수 있습니다(본인도 다시 못 씁니다). 서로 이웃은 유지되고 하트 수는 초기화되며, 30일에 한 번만.

초기화와 삭제

  • 꾸미기 초기화 — 테마·색만 / 위젯 구성만 / 스티커만 / 사진만 / 직접 정한 글자색만 / 전체. 글·갤러리·방명록은 지워지지 않습니다.
  • 어둡게↔밝게를 바꿨는데 글자가 배경에 묻히면 직접 정해 둔 색(글 목록 제목 색·헤더 글씨색·카드 색·위젯 글자색)이 남아 있는 것입니다. 「직접 정한 글자색만」 초기화로 한 번에 지울 수 있습니다.
  • 홈 삭제(탈퇴) — 내 주소를 직접 입력하고 두 번 확인하면 홈과 글·사진·방명록이 전부 삭제됩니다. 되돌릴 수 없고 주소는 풀립니다.
초기화·삭제는 복구되지 않습니다. 하기 전에 백업부터.
